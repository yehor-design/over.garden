# OverGarden — Покриття за шарами × локалями (LAYER_COVERAGE)

**Що це:** для кожного шару архітектури каталогу (L1–L6) — окремо UA і окремо BG — чим покрито (з вердиктом джерела) і що ПРОГАЛИНА. UA і BG ніде не злиті.
**Зведено з:** `API/_SYNTHESIS/SOURCES_REGISTRY.md` (який зведено з B1–B7 + Additional). Деталі джерел і провенанс — у реєстрі.
**Дата генерації:** 2026-06-06.
**Статус повноти:** повний за шарами; критичні ПРОГАЛИНИ перелічені в кінці, відсортовані за критичністю для запуску.

**Легенда покриття:** ПОКРИТО (є придатне джерело з робочим доступом + дозволеною комерцією) · ЧАСТКОВО (джерело є, але з тертям: PDF/без API/ліцензія під питанням/неповне) · ПРОГАЛИНА (немає придатного джерела — будувати або не закрито).

---

## L1 — Таксономічний/видовий кістяк (скелет видів + видовий вернакуляр)

### UA
- **Скелет видів — ПОКРИТО.** WFO (CC0), Catalogue of Life (CC BY 4.0), GBIF Backbone (CC BY 4.0), EPPO (Open Data, комерція), GRIN/USDA (public domain) — усі дають видовий кістяк з дозволеною комерцією. UA-специфічне зведення: **Ukraine_SL crosswalk** (`ukraine_sl_taxonomy.xlsx`) мапить UA-номенклатуру → Euro+Med/GBIF/WCVP/WFO (вирішує таксономічні конфлікти UA). Вердикти: USE / USE (public domain).
- **Видовий вернакуляр UA — ЧАСТКОВО → ПРОГАЛИНА в офіційних таксономічних джерелах.** GBIF/COL/WFO: uk-назви на рівні виду **майже відсутні** (підтверджено фетчем томата/огірка/винограду — B2). Часткові носії: GRIN (uk оспорено — `КОНФЛІКТ`), iNaturalist (UA сильна, USE-WITH-CONDITIONS), EOL (фільтрувати NC), UkrBIN (через GBIF, ліцензія під питанням). **Потенційний закривач прогалини — PESI/Euro+Med** (>140k вернакуляр 89 мов вкл. UA) — `[single-source-critical]`, не виміряно.
- **Підсумок L1 UA:** скелет — ПОКРИТО; видові UA-народні назви — ЧАСТКОВО, основний шлях через PESI(перевірити)+Wikidata+iNaturalist+EOL, а не через міжнародні backbone.

### BG
- **Скелет видів — ПОКРИТО.** Ті самі backbone (WFO/COL/GBIF/EPPO/GRIN). BG-розмежування присутності видів — через **Euro+Med PlantBase** (>92% судинних рослин Європи/Середземномор'я з регіоном BG). Вердикти: USE.
- **Видовий вернакуляр BG — ЧАСТКОВО → ПРОГАЛИНА.** GBIF/COL/WFO: bg-назви видового рівня **майже відсутні**. Часткові носії: **PESI** (89 мов вкл. BG — `[single-source-critical]`, не виміряно), Wikidata (CC0), EOL (фільтрувати NC), **bgflora** (BG/EN ~3 800 видів, але ліцензія `КОНФЛІКТ` — комерція під питанням). iNaturalist BG-локаль **слабка**.
- **Підсумок L1 BG:** скелет — ПОКРИТО; видові BG-народні назви — ЧАСТКОВО (слабше за UA: iNat-BG слабкий, bgflora-ліцензія проблемна), основна надія — PESI(перевірити)+Wikidata.

## L2 — Канонічний посів сортів/порід (офіційні канонічні назви)

### UA
- **Сорти рослин — ПОКРИТО (з одним конфліктом).** Державний реєстр сортів рослин (data.gov.ua ccf95f4a / minagro XLSX) — ~13 790 сортів, **CC BY 4.0 (комерція з атрибуцією)** = найчистіше офіційне джерело UA. Вердикт: **USE.** `КОНФЛІКТ`: один файл (B1-FILE4) оспорює наявність актуального CSV (бачить лише PDF/точковий пошук). Доповнення: EU Common Catalogue (UA-сорти лише якщо зареєстровані в ЄС).
- **Породи (бджоли/тварини) — ПОКРИТО.** Закон №1492-III (3 районовані породи бджіл: карпатська, українська степова, поліська) + Реєстр селекційних досягнень у тваринництві (data.gov.ua, XLS, відкриті дані, комерція ОК). Малий hardcode-готовий набір. Латину сіяти з GBIF/CoL (оспорена — нести обидві). Вердикт: **USE.**
- **Підсумок L2 UA:** ПОКРИТО для рослин (verify CSV) і для порід (hardcode малого набору). Спільна слабкість: офіційні джерела **без поля синонімів** → L3 не закривають.

### BG
- **Сорти рослин — ЧАСТКОВО.** Официална сортова листа (ИАСАС) — рівень сорту, але **лише PDF, без CSV/API** → потрібен парсер/OCR; **ліцензія невизначена** (`КОНФЛІКТ`: «вільно» FILE4 vs «обережно, запит» FILE2/B4). EU Common Catalogue покриває BG-зареєстровані сорти (`КОНФЛІКТ` про наявність API). Вердикт: **USE-WITH-CONDITIONS** (парсити PDF + запит IASAS про права).
- **Породи — ЧАСТКОВО.** ИАСРЖ/IASRJ — 1 місцева бджола (macedonica/rodopica) + автохтонні породи з BG/EN назвами, **але «всі права захищені», лише HTML без API → ручний збір/запит ЗДОІ**. Юридичне звуження: імпорт чужих рас заборонений. Вердикт: **USE-WITH-CONDITIONS.**
- **Підсумок L2 BG:** ЧАСТКОВО для обох — офіційні дані існують, але замкнені у PDF/HTML без машинного доступу й з невизначеною/закритою ліцензією. Тут BG структурно слабший за UA.

## L3 — Збагачення аліасами/синонімами (UA/RU/BG/EN, регіональні, варіанти написання)

> **Це найважчий і moat-критичний шар** (саме сюди впирається fail-loud-застереження MVP-брифа: «сорти значно менш канонічні за фільми/птахів — багато народних/локальних/лендрейс-назв»). Офіційні реєстри (L2) **не мають поля синонімів**; міжнародні backbone (L1) **майже не несуть uk/bg** на рівні виду й **взагалі не несуть рівня сорту**.

### UA
- **Видовий рівень — ЧАСТКОВО.** Wikidata (CC0, фрагментарно — виміряти), **PESI/Euro+Med** (89 мов вкл. UA — `[single-source-critical]`, не виміряно — потенційно головний закривач), GRIN (uk оспорено), iNaturalist (UA сильна), EOL (фільтрувати NC), EPPO (uk не виміряно). НЦГРРУ має поле «синонім назви accession» (прямий запит).
- **Сортовий рівень (культивари) — ПРОГАЛИНА.** **Жодне відкрите міжнародне джерело не дає UA-аліасів на рівні сорту.** CPVO/UPOV (найбагатші деномінації) — юридично закриті для комерції. Продавці (Florium тощо) — лише після дозволу/партнерського фіду. → закривати **власним збором + краудсорсом (Untappd-механіка) + куруванням**.
- **Підсумок L3 UA:** видовий — ЧАСТКОВО (PESI/Wikidata/iNat); **сортовий — ПРОГАЛИНА (build).**

### BG
- **Видовий рівень — ЧАСТКОВО (слабше за UA).** Wikidata (CC0), **PESI** (89 мов вкл. BG — `[single-source-critical]`), EOL (NC-фільтр), bgflora (BG/EN, ліцензія `КОНФЛІКТ`), EU Common Catalogue «Variety Trade Names» (для BG-сортів). iNat-BG слабка. IPGR Sadovo має folk-names донорів — **але не публічні** (локальні Excel, не в EURISCO).
- **Сортовий рівень — ПРОГАЛИНА.** Те саме: CPVO/UPOV закриті для комерції; BG-реєстр без синонімів; → власний збір + краудсорс + курування.
- **Підсумок L3 BG:** видовий — ЧАСТКОВО (g-джерела слабші: bgflora-ліцензія, iNat-BG слабкий, IPGR folk-names закриті); **сортовий — ПРОГАЛИНА (build).**

## L4 — Здобуття довгого хвоста (народні/лендрейс поза реєстрами: генбанки / скрейп / UGC)

### UA
- **Генбанки — ЧАСТКОВО.** EURISCO/Genesys (UA ~43 617 accessions; **anti-compete + redistribution-ban ліцензія** → юрперевірка) + НЦГРРУ прямий запит (поле «синонім», лендрейси). Вердикт: USE-WITH-CONDITIONS.
- **Скрейп продавців/форумів — ЧАСТКОВО / юридично під питанням.** Florium/Яскрава — ToS немає, sui generis (Закон №2811-IX) без судової практики → дозвіл/партнерський фід. Форуми — лише витяг назв. Вердикт: USE-WITH-CONDITIONS (після дозволу).
- **UGC — основний шлях (build).** Краудсорс через Untappd-механіку (спільний запис сорту) + гейтоване створення + курування — єдиний масштабований шлях до народного хвоста.
- **Підсумок L4 UA:** ЧАСТКОВО з генбанків (з юрперевіркою) + ПРОГАЛИНА, що закривається UGC (build).

### BG
- **Генбанки — ЧАСТКОВО.** EURISCO/Genesys (BG ~69 931; та сама anti-compete ліцензія) + IPGR Sadovo прямий запит (**folk-names НЕ публічні** — критична прогалина). Вердикт: USE-WITH-CONDITIONS.
- **Скрейп маркетплейсів — юридично обмежено.** bazar.bg/OLX.bg/eMAG.bg — ToS-заборони (частково оспорені), sui generis EU, DSA; продукт «спрямований на BG/ЄС» → EU-режим. OLX має легальний Developer API. Вердикт: переважно REJECT-скрейп / USE-WITH-CONDITIONS (API/дозвіл).
- **UGC — основний шлях (build).** Те саме, що UA.
- **Підсумок L4 BG:** ЧАСТКОВО з генбанків (folk-names закриті) + жорсткіший правовий режим скрейпу + ПРОГАЛИНА, що закривається UGC (build).

## L5 — Двигун матчингу/дедупу (fuzzy-match для typeahead + entity resolution, кирилиця)

### UA
- **ПОКРИТО (build з OSS).** Typeahead: **Meilisearch** (MIT, кирилиця uk з коробки) — рекомендований; альт. Typesense (ICU uk, але GPLv3-ризик). Дедуп: **Splink** (Jaro-Winkler, Unicode) або dedupe (уникати unidecode). Folding UA↔RU: власна символьна мапа + ICU/CyrTranslit. Core fuzzy: RapidFuzz (MIT). pg_trgm — лише внутрішньо/fallback (слабкий на коротких UA-назвах — `КОНФЛІКТ`). Вердикти: USE / USE-WITH-CONDITIONS.
- **Підсумок L5 UA:** ПОКРИТО стандартним OSS-стеком (комерція ОК за MIT). Ризики — вибір Typesense(GPLv3) vs Meilisearch(MIT) і пастка unidecode.

### BG
- **ПОКРИТО (build з OSS).** Той самий стек: Meilisearch (Charabia bg) / Typesense (ICU bg); Splink; RapidFuzz; ICU/CyrTranslit (bg). Folding BG — власна мапа.
- **Підсумок L5 BG:** ПОКРИТО тим самим OSS-стеком. (Двигун — універсальний для обох локалей; локальна різниця лише в folding-мапах і synonym-сетах.)

## L6 — Генерація варіантів назв (транслітерація / фонетика / клавіатура)

### UA
- **Транслітерація — ПОКРИТО.** cyrtranslit (MIT, uk), translitua (КМУ-2010 UA; ліцензія перевірити), ICU (BGN). 
- **Фонетика — ЧАСТКОВО.** ukrainian-tts-preprocessing (ByT5, Apache-2.0, UA) — є; готового кириличного Soundex/Metaphone для UA в MIT немає (fonetika — лише RU). 
- **Клавіатура — ПОКРИТО.** nlpaug (UA `lang='uk'` built-in), multypo (UA розкладку реєструвати). ЙЦУКЕН-довідники.
- **Підсумок L6 UA:** транслітерація+клавіатура ПОКРИТО; фонетика ЧАСТКОВО (ML-шлях ByT5).

### BG
- **Транслітерація — ЧАСТКОВО.** cyrtranslit (bg), ICU (BGN), translitbg/vasov (BG Act 2009 — але Go/Elixir/JS, потрібен порт у Python). BG-стандарт 2009 — кастомні пакети.
- **Фонетика — ПРОГАЛИНА.** **Готових BG-фонетичних бібліотек практично немає → будувати з нуля** (наскрізна знахідка B5).
- **Клавіатура — ЧАСТКОВО.** BG дводольна (BDS 5237-78 + Phonetic) → дві окремі розкладки реєструвати вручну (multypo/nlpaug `model_path`); готових немає.
- **Підсумок L6 BG:** транслітерація+клавіатура ЧАСТКОВО (ручні пакети/порт); **фонетика — ПРОГАЛИНА (build from scratch).**

## Прогалини шарів × локалей, відсортовані за критичністю для запуску

**Критичність 1 — БЛОКУЄ moat (мережевий ефект через спільний запис сорту/породи):**
- **L3 сортовий рівень, UA — ПРОГАЛИНА.** Немає відкритого джерела UA-аліасів сортів; закривати краудсорсом (build). Без цього однакові сорти фрагментуються на дублікати.
- **L3 сортовий рівень, BG — ПРОГАЛИНА.** Те саме для BG.
- **L3 видовий рівень, UA/BG — частково ПРОГАЛИНА, тримається на ОДНОМУ неперевіреному джерелі (PESI `[single-source-critical]`).** Якщо PESI не дає реального uk/bg-покриття — лишається лише Wikidata(фрагментарно)+iNat(UA)/слабкий-BG.

**Критичність 2 — БЛОКУЄ запуск локалі BG (UA тут сильніший):**
- **L2 сорти, BG — ЧАСТКОВО (PDF-only + ліцензія невизначена).** Потрібен PDF-парсер + правовий дозвіл IASAS.
- **L2 породи, BG — ЧАСТКОВО (HTML/закрита ліцензія, ручний збір).**
- **L4 BG — folk-names генбанку (IPGR Sadovo) НЕ публічні + жорсткіший скрейп-режим.**

**Критичність 3 — інженерний борг, не блокер (build):**
- **L6 фонетика BG — ПРОГАЛИНА (з нуля).** L6 фонетика UA — ЧАСТКОВО (ByT5).
- **L6 транслітерація/клавіатура BG — ЧАСТКОВО (порт/ручні пакети).**

**Критичність 4 — потрібна перевірка/рішення, не прогалина даних:**
- **L2 сорти UA — verify CSV-існування** (`КОНФЛІКТ` B1-FILE4).
- **L5 — вибір двигуна** (Meilisearch MIT vs Typesense GPLv3) і пастка unidecode.
- **Bee-латина (L1/L2) оспорена** — нести обидві версії, не блокер.

**Спільна універсальна сила (надійно, обидві локалі):** L1 скелет видів (відкриті backbone), L5 двигун (OSS-стек), L2 канонічний посів порід бджіл (малий hardcode-набір) — будуються один раз.
**Спільна універсальна слабкість (обидві локалі):** L3 сортовий вернакуляр — ніде не куплений, лише build; видовий uk/bg-вернакуляр тримається на неперевіреному PESI.
