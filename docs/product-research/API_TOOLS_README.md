# Маніфест — Дослідження інструментів зіставлення / дедупу назв

**Що це.** Незалежне deep-research-дослідження інструментів для задачі: користувач вводить коротку власну назву (сорти рослин / породи тварин, переважно укр/рос/болг кирилицею + латинська транслітерація) → система допомагає потрапити на один правильний наявний запис попри помилки, різні мови й написання; каталог тримається чистим від дублів. Продукт — закритий комерційний.

**Дата:** 2026-06-08
**Метод:** deep research (ітеративний, багатоджерельний) + саб-агенти (1 на задачу для discovery; окрема фаза evaluation).
**Мови пошуку:** англійська, українська, російська, болгарська (та інші за потреби). Мова файлів: українська.
**Статус прогону:** ✅ ЗАВЕРШЕНО. 9 discovery-файлів + 9 evaluation-файлів + підсумок. Прогалини названо чесно.

## Структура
- `raw/` — discovery, по одному файлу на задачу (знайдені кандидати free+paid з посиланнями на першоджерела).
- `evaluation/` — оцінка кожного кандидата за 5 критеріями + рекомендація по задачі.
- `_SUMMARY.md` — підсумок і рекомендований стек (пише оркестратор).
- `_README.md` — цей маніфест.

## Дев'ять задач
- **A** — Пошуковий рушій (typeahead + typo-tolerance + кирилична токенізація + ранжування) → `raw/A_search_engine.md`
- **B1** — Нормалізація тексту (case/Unicode folding, NFC/NFKC) → `raw/B1_normalization.md`
- **B2** — Транслітерація кирилиця↔латиниця (укр/рос/болг, стандарти романізації) → `raw/B2_transliteration.md`
- **B3** — Фонетичне зіставлення (Soundex/Metaphone/Double Metaphone/Beider-Morse для кирилиці) → `raw/B3_phonetic.md`
- **B4** — Клавіатурні помилки (keyboard adjacency для укр/рос/болг розкладок) → `raw/B4_keyboard.md`
- **B5** — Генерація варіантів написання (spelling variant / typo / augmentation) → `raw/B5_variant_generation.md`
- **C1** — Схожість рядків (Levenshtein/Jaro-Winkler/token-based) → `raw/C1_string_similarity.md`
- **C2** — Крос-мовний матч імен (cross-script name matching) → `raw/C2_name_matching.md`
- **D1** — Дедуп / зв'язування записів (record linkage / entity resolution) → `raw/D1_dedup.md`

## Жорсткі обмеження (визначають оцінку)
- Ліцензія має дозволяти вбудовування в **закритий комерційний** продукт (permissive — ОК; GPL/LGPL/AGPL/SSPL — прапор ризику).
- Критична підтримка **кирилиці укр/рос/болг** (не лише латиниця/англ).
- Можливий self-host; команда невелика; обсяг даних зростатиме.

## Перелік файлів (18 + 2)
- `_SUMMARY.md` — підсумок і рекомендований стек (читати першим).
- `raw/`: `A_search_engine.md`, `B1_normalization.md`, `B2_transliteration.md`, `B3_phonetic.md`, `B4_keyboard.md`, `B5_variant_generation.md`, `C1_string_similarity.md`, `C2_name_matching.md`, `D1_dedup.md`.
- `evaluation/`: `EVALUATION_A.md`, `EVALUATION_B1.md`, `EVALUATION_B2.md`, `EVALUATION_B3.md`, `EVALUATION_B4.md`, `EVALUATION_B5.md`, `EVALUATION_C1.md`, `EVALUATION_C2.md`, `EVALUATION_D1.md`.

## Метод і верифікація
Фаза A — 9 паралельних discovery-саб-агентів (deep research, free+paid, усі мови). Фаза B — 9 evaluation-саб-агентів (5 критеріїв + рекомендація). Оркестратор верифікував: усі файли на місці (33–55 КБ), без таблиць/JSON; спот-перевірено навантажені ліцензії (Typesense GPL-3 серверний демон; Zingg AGPL-3.0; Elasticsearch SSPL/AGPLv3/Elastic v2 з 2024; jellyfish — BSD-2, не MIT). Evaluation-агенти додали корекції: iso9 фактично permissive; **Augmentex KartaSlov-дані — CC BY-NC-SA (некомерційна)**; укр. морфологія в Lucene-родині існує (`UkrainianMorfologikAnalyzer`).

## Нерозв'язане / прогалини (чесно)
- **B3 фонетика — українська + болгарська:** готового немає, будувати власне (рос. закрито через Apache Commons Beider-Morse / fonetika).
- **B4 клавіатура — болгарська (БДС):** немає готових даних, будувати вручну в clavier (рос/укр закрито).
- **B2 транслітерація — болгарська Streamlined під permissive:** немає; писати власну таблицю. Зворотність — лише через ISO 9.
- **C2 крос-мовний матч — OSS:** немає зрілого permissive-рішення з доказовою кирилицею; будувати власний конвеєр B2+B3+C1 або платити Senzing.
- **Наскрізна болгарська** — найслабша мова в усіх задачах; закладати окремий бюджет.
- **Бенчмарків якості на коротких кириличних назвах немає для жодного інструмента** — обов'язковий PoC на власних даних.
- **Юридична перевірка** GPL/AGPL/SSPL під конкретну архітектуру (окремий демон vs лінкування) — за юристом.
