## (i) ПРЯМО ДІЄВЕ ДЛЯ OverGarden ЗАРАЗ

### A. Для H6-smoke (одна вручну-засіяна сторінка «сорт-у-регіоні», `KILL_CRITERIA_PREREG_v2.md §8`)

**A1. SSR усього, включно з JSON-LD у початковому HTML — єдина майже-одностайна, контрольовано-підтверджена вимога.** ChatGPT/Claude/Perplexity-боти НЕ виконують JS (Vercel/MERJ, >500M фетчів: «none of the major AI crawlers render JavaScript»; GPTBot/OAI-SearchBot/ClaudeBot/Claude-SearchBot/PerplexityBot/Meta-ExternalAgent/Bytespider — нуль виконання JS; рендерять лише Googlebot-WRS→Gemini/AIO та Bingbot) — [Compass M-1/M-9], [Звіт Z-6]. Контент за JS-оболонкою = невидимий для AI; «бінарна» проблема (видно або ні, без часткового кредиту). Перевірка: DevTools з вимкненим JS. → **ПРЯМО-ЗАСТОСОВНЕ.** ⮕ ПІДТВЕРДЖУЄ `ENTRY_DATA §4` (SSR/краулер-бачить-контент) і `B5 v1 §6 мітигація (е)` — **підсилює контрольованим доказом**.

**A2. Аудит Cloudflare/WAF, щоб він не блокував AI-ботів (429/JS-челендж) попри дозвільний robots.txt; не довіряти GSC URL Inspection для AI-доступу; GA4 НЕ бачить AI-фетчі (вони не виконують клієнтський JS) — моніторити серверні логи.** ChatGPT/Claude витрачають >34% фетчів на 404 (vs 8% Googlebot) — інфраструктура AI ще незріла — [Compass M-9]. → **ПРЯМО-ЗАСТОСОВНЕ (build-чекліст).** ⮕ РОЗШИРЮЄ `ENTRY_DATA §4`/`§6` (інженерні прогалини): додає WAF-пастку + лог-моніторинг як окремі вимоги.

**A3. Контент-важіль = first-hand статистика + дати + цитати, один атомарний факт на сторінку, відповідь у перших 100 словах (40–60-слівна пряма відповідь під заголовком).** Princeton GEO: статистика/цитати/посилання-на-джерела піднімають видимість у генеративній відповіді ~до 30–40% відносно; keyword stuffing — без стабільної користі, −10…−20% (токсично) — [Princeton-GEO §4/Table 1], [CAT C-3], [ROLE R1-5]. «8+-слівний» довгий хвіст: цитування зросло 7× з 2024 — [Звіт Z-7]. Правило «одна атомарна теза/сторінка + відповідь у 100 словах» — [Звіт Z-7]; 40–60 слів — [Masterclass 6-13], [Clarity 3-7], [Jasper]. ⚠ Числа Princeton — **ПОТЕНЦІЙНО ЗАСТАРІЛІ** (експерименти на GPT-3.5-class до масових AIO; сам документ це флагує), якісний висновок — чинний. → **ПРЯМО-ЗАСТОСОВНЕ.** ⮕ ПІДТВЕРДЖУЄ тезу proof-data на рівні контенту: датований журнальний запис із реальними числами (врожай/дата/регіон) природно несе саме той клас контенту, що його ці движки винагороджують.

**A4. Механізм, який дозволяє DR=0-сторінці бути процитованою БЕЗ топ-10: passage-relevance + Query Fan-Out (AIO на Gemini 3, 27.01.2026).** Движок генерує десятки синтетичних під-запитів; цитоване джерело може не ранжувати за головним запитом, але ідеально відповідати одному вузькому під-запиту на рівні абзацу — [CAT C-8], [Compass M-7], [Masterclass 6-11/6-18]. Це **найсильніший про-cold-start-сигнал** у всьому корпусі й технічна основа H6-smoke: сторінка, що відповідає «коли висаджувати [сорт] у [регіоні]» там, де чистої відповіді ще немає, може виграти fan-out-під-запит без доменного авторитету. → **ПРЯМО-ЗАСТОСОВНЕ.** ⮕ РОЗШИРЮЄ/частково ПОМ'ЯКШУЄ `B5 v1 §6 конфаунд C` (новий домен без авторитету): корпус дає конкретний шлях обходу C — глибока вузько-релевантна сторінка, не head-ранжування.

**A5. Цільовий движок для першого smoke-зонда — Perplexity.** Цитує джерела в ~97% відповідей ([Otterly O-9]), краул-базований і оновлюється на індексації (на відміну від статично-тренованого ChatGPT — [DestCanada 1-21]), винагороджує оригінальні дані/провенанс ([Jasper Fig D], [Clarity]); T3-натяк, що «Perplexity → локальні ресурси» ([Deep D-2]) — неперевірено, але варте зонда. **Міряти агреговану видимість % за 60–100 прогонів, НІКОЛИ не «позицію в AI».** Відтворюваність: <1/100 шанс того самого списку брендів двічі, <1/1000 — того самого порядку (SparkToro/Fishkin, 2 961 прогін), АЛЕ агрегований % за 60–100 прогонів — стабільний і валідний — [Compass M-12], [CAT C-14]. → **ПРЯМО-ЗАСТОСОВНЕ.** ⮕ РОЗШИРЮЄ інструмент H6 (`DRIVE2_CANON_v1.md §4` жива пост-лонч перевірка) + `B2_METRICS`: додає Share-of-Model-метод (60–100 промптів) поряд з organic-K.

**A6. Schema = гігієна, НЕ важіль AI-цитування.** Контрольований тест (Ahrefs, 1 885 сторінок, що додали JSON-LD, matched difference-in-differences, по 3 контролі на кожну): приріст цитування = +2.2% ChatGPT / −4.6% AIO = статистично НУЛЬ (а −4.6% для AIO значущий проти контролю) — [Compass M-2], [Звіт Z-1]. Кореляція «3× / 2.1–4.2× більше цитувань зі schema» РЕАЛЬНА, але це кореляція приналежності, не причинність ([ROLE R1-10] сам це флагує). Першоджерела: Ryan Levering (Google, Search Central Live Toronto, 04.2026) «Schema is used as context served to models when doing fanouts»; Fabrice Canel (Microsoft, SMX 03.2025) «schema markup helps Microsoft's LLMs understand your content» — тобто schema допомагає РОЗУМІННЮ під час fan-out (Google/Bing), не прямому цитуванню — [Звіт Z-2]. Google (05.2026): «Structured data isn't required for generative AI search… no special markup you need to add» — [ROLE R1-10]. → **УМОВНО-ЗАСТОСОВНЕ** (впроваджувати Organization+Person+Article для розуміння Google/Bing; не очікувати цитувань). ⮕ ПІДТВЕРДЖУЄ [Delta] + `B5/ENTRY` (schema = гігієна Google/Bing-екстракції). **СУПЕРЕЧИТЬ** будь-якому залишковому «schema → AI-цитування».

**A7. НІКОЛИ не емітити шаблонний/дубльований JSON-LD на тонких стабах — це НЕГАТИВНИЙ (спам) сигнал; розмітка мусить точно відповідати видимому тексту DOM.** — [CAT C-9]. Клієнтський JSON-LD через Google Tag Manager AI-боти не бачать (не виконують JS) — серверний рендер обов'язковий — [CAT C-15 п.4], [Compass M-9]. → **ПРЯМО-ЗАСТОСОВНЕ (build-обмеження).** ⮕ ПІДТВЕРДЖУЄ/ЗАГОСТРЮЄ `B5 v1 §6` (data-template-кара): однакова boilerplate-schema на тисячах сорт×регіон-стабів = подвійна пастка (thin + templated-spam).

### B. Що повний публічний шар МУСИТЬ поважати

**B1. Несучий ризик: програматичний скелет «об'єкт×регіон» виглядає як саме той тонкий/шаблонний/масовий контент, який enforcement 2024–2026 придушує.** Named-механізми з корпусу: **MAD-M** (SSRN 2026) — коли AI-генерований контент перевищує ~60% потоку бренду, настає системна алгоритмічна демоція в усіх каналах ([ROLE R1-9]); templated-JSON-LD = спам ([CAT C-9]); keyword-stuffing −10…−20% ([CAT C-3/C-15]); «scaled content abuse карає однаково людину й AI». Вердикт корпусу: **індексована поверхня мусить бути домінована СПРАВЖНІМ first-hand UGC; програматичні стаби мінімізувати або збагатити.** → **ПРЯМО-ЗАСТОСОВНЕ.** ⮕ **СИЛЬНО ПІДТВЕРДЖУЄ** `B5 v1 §3` (cold-start-дедлок: каталог-стаби→noindex), `§6 конфаунд B`, `§7` (інверсія фазування: редакційний+first-hand-сід у Фазу 1, програматика у Фазу 2). Корпус дає `B5 v1` зовнішні named-докази того, що раніше було «загальним принципом».

**B2. Замок локації: robots.txt НЕ може його забезпечити.** robots.txt — добровільний, юридично-незобов'язувальний протокол; «сірі»/нові AI-краулери його ігнорують ([ROLE R1-3], arXiv 2024 + legal study, T1). Контрольований тест Cloudflare (04.08.2025): Perplexity відповідав про щойно-створені, ніколи-не-опубліковані домени зі строгим robots.txt-блоком, витягуючи контент через спуфнутий User-Agent і приховані IP ([CAT C-2]). User-triggered-боти (ChatGPT-User/Claude-User/Perplexity-User) роблять live-фетч в обхід robots.txt ([ROLE R1-1]). → **ПРЯМО-ЗАСТОСОВНЕ.** ⮕ **ПІДТВЕРДЖУЄ + ЗАГОСТРЮЄ** `ENTRY_DATA §5`/`AC-S9b` + `B5 v1 §5`: точні координати мусять бути заблоковані на РІВНІ ДАНИХ (ніколи не рендеритись у відданому HTML, не в title/URL/sitemap) — robots.txt це НЕ контроль приватності. Корпус дає доказ, якого в артефактах не було.

**B3. AI-видимість ≠ трафік.** Pew (липень 2025, 900 дорослих US, реальна браузер-поведінка, 68 879 пошуків): з AI-резюме клік на традиційний результат у 8% візитів проти 15% без; клік усередині AIO = лише 1%; 26% завершують сесію — [Compass M-5], [Звіт Z-5]. Seer: для AIO-запитів органічний CTR падає 1.76%→0.61% (−65%) у середньому, АЛЕ якщо ти Є цитованим джерелом — +120% кліків на показ ([Compass M-8] — різні популяції, не усереднювати). → **ПРЯМО-ЗАСТОСОВНЕ (стратегічне обмеження).** ⮕ **ПІДТВЕРДЖУЄ** `B2_METRICS` (відмова від vanity) + **РОЗШИРЮЄ з напругою**: H6-organic-K (клік-базований) структурно НЕ-ДОЛІЧУЄ цінність AI-цитування, бо AI-поверхні переважно zero-click → AI-цитування потребує ОКРЕМОГО impression-базованого інструменту (Share-of-Model, A5), відмінного від organic-K. Це напруга з frozen-калібратором `KILL §8` (organic-K<0.3 два квартали) — **флагую для оператора, frozen не редагую** (пор. вже наявний флаг «траєкторія-не-рівень» `B5 v1 §8`).

**B4. Свіжість допомагає — але розщеплено по движках.** ChatGPT/Perplexity цитують свіже (Seer: 65%/79%/89% посилань на контент <1/2/3 років; ChatGPT медіана ~958 днів) — [Compass M-6], [Deep D-3]. Google AIO — НЕ свіжо-упереджений (медіана цитованої сторінки ~14 міс / ~3.9 року ≈ звичайна органіка) — [ROLE R1-7], [Deep D-3]. → **УМОВНО-ЗАСТОСОВНЕ.** ⮕ ПІДТВЕРДЖУЄ перевагу живого журналу [Delta], але уточнює: безперервні датовані записи допомагають ChatGPT/Perplexity більше, ніж Google AIO (який домінує в UA-ринку за [Delta]).

**B5. Topical authority винагороджується; «GEO = ~80% доброго SEO».** Бренди з вузькою нішевою спеціалізацією цитуються 2.4× частіше за генералістів рівного DA (BrightEdge) — [CAT C-6]; deep-сторінки (≥2 кліки від home) = 82.5% AIO-цитувань — [Звіт Z-4]. Скептик-консенсус (The Verge, Jeremy Moser, Lily Ray, Rand Fishkin): «якщо GEO-сервіс не каже, що 80% успіху — це звичайне добре SEO, він продає зміїну олію» — [CAT C-13], [Звіт Z-9]. → **ПРЯМО-ЗАСТОСОВНЕ.** ⮕ ПІДТВЕРДЖУЄ вузький садово-бджолярський фокус OverGarden як перевагу + `DRIVE2_CANON`/`B5` ставку на глибокі об'єкт/сорт-сторінки. Резистувати «магічним» GEO-тактикам.

## (ii) ТЕМАТИЧНІ ЗНАХІДКИ (з тегами застосовності й інтеграції)

### Тема 1 — Технічне SEO й контроль індексації
- **SSR/HTML-only** (A1/A2) — найдоказовіша вимога корпусу. ⮕ ПІДТВЕРДЖУЄ `ENTRY_DATA §4`.
- **`lastmod` ISO-8601 з точним timestamp** — генеративні движки ігнорують `changefreq`/`priority`, покладаються ЛИШЕ на `lastmod`; один sitemap-дерево до 2.5 млрд URL (Bing Webmaster, 07.2025, T1) — [CAT C-10]. → ПРЯМО-ЗАСТОСОВНЕ: емітити точний `lastmod` на кожному журналі/агрегації (Bing→ChatGPT-шлях). ⮕ РОЗШИРЮЄ `ENTRY_DATA §4` (чисті метадані).
- **IndexNow** (Bing, T1) — допомагає AI бачити поточну версію — [Deep D-7]; вендорський контекст [SeaSeek/Otterly]. → УМОВНО (низька вартість).
- **robots.txt: дозволити search/retrieval-боти, блокувати тренувальні** — OpenAI search-покриття зросло 4.7%→>55% сайтів, тренувальне впало 84%→12%; 79% топ-новинних блокують ≥1 тренувального бота — [Compass M-11]. ClaudeBot craw-to-referral ~70 900:1 (червень 2025) — економіка блокування тренування виправдана — [CAT C-1]. → ПРЯМО-ЗАСТОСОВНЕ: allow OAI-SearchBot/Claude-SearchBot/PerplexityBot/Googlebot; окремо вирішити GPTBot/ClaudeBot/Google-Extended/Applebot-Extended (тренування). ⮕ ПІДТВЕРДЖУЄ намір «пусти публічне, закрий приватне/тренування» (узгоджено з [Delta]/WS2). **GPTBot HTML-only + поважає HTTP 402 як do-not-train (Q1 2026)** — [ROLE R1-2] (нішевий важіль).
- **Блокування тренувальних ботів майже не знижує цитування; над-блокування коштує трафіку** — узгоджено з [Delta].

### Тема 2 — Якість контенту й E-E-A-T
- **First-hand досвід + оригінальні дані + явне авторство = ядро цитування** (A3). Усі тіри сходяться. ⮕ ПІДТВЕРДЖУЄ first-hand-UGC-тезу OverGarden (`DRIVE2_CANON §3`). [E-GEO] (академічний, 11.2025): фактологічність — РАНГ-ПОЗИТИВНА в сучасному GPT-4o-реранкері (12/15 оптимізованих промптів зберігають factuality), наратив без фактів (Storytelling, −4.03) — найгірший. → ПРЯМО-ЗАСТОСОВНЕ: журнальні історії мусять нести конкретні датовані факти, не замість них.
- **«Унікально-розташований, щоб говорити про це» (uniqueness) — точний опис moat'у OverGarden** ([Masterclass 6-13/6-18], [Compass M-5 «information gain»-споріднене]): реальні локальні датовані докази, яких ніхто інший не має. → ПРЯМО-ЗАСТОСОВНЕ.
