# OverGarden — ПОВНА АРХІТЕКТУРА СТОРІНОК (дерево вкладеності), **v1**

**Регенеровано 2026-06-23** з `v0` + усіх 7 закритих рішень (`OverGarden_PAGE_ARCH_DECISIONS_v0.md`, D1–D7). Це **карта типів** (шаблонів) для по-сторінкової документації: «Сторінка-СОРТ» = один тип/один документ, не окремий запис на сорт.

**Що змінилось vs v0:** агрегації схлопнуто в один двигун (D2); auth/legal/account піднято з `[ІНФЕР]` у `[MVP]` (D1); додано зони/поверхні (Admin-курація, Архів, auth-модал, запит-на-видалення, перемикач мови, список чернеток); профіль+граф дедупльовано в `noindex` (D6); локаль-модель = 3 мовні папки (D4); видалення→410+erasure-on-request (D5); типи поверхонь класифіковано share-test'ом (D3); крос-сторінки = `noindex`-до-порогу (D7).

## ЛЕГЕНДА

**Статус скоупу:** `[MVP]` · `[MVP-крит]` (MVP + лонч-блокер) · `[Ф2]` (фаза-2, demand-gated, `noindex` до порогу) · `[POST]` (post-MVP, не будувати v0) · `[ВНУТР]` (внутрішня поверхня / не публічна).

**Тип поверхні (D3 share-test):** `(маршрут)` власний URL · `(аркуш)` повноекранний transient композер, БЕЗ URL · `(модал)` спливне вікно, повертає в контекст · `(стан)` стан сторінки · `(дія)` дія без сторінки · `(секція)` блок усередині сторінки, вартий окремого опису.

**Індексація:** `{SSR}` серверний рендер, ІНДЕКСОВАНИЙ (несе рів) · `{noindex}` публічно-видимий, shareable, але НЕ в Google · *(автентифікований SPA — без тегу)*.

## НАСКРІЗНІ ВИМІРИ (НЕ дублюю у вузлах)

1. **Локаль (D4).** Три мовні папки на `over.garden`: `/uk/` (hreflang `uk`) · `/bg/` (hreflang `bg`) · `/ru/` (hreflang `ru`). hreflang ТІЛЬКИ-МОВНИЙ. «Ринок» — runtime (geo-default + market-filtered switcher: UA={uk,ru} default uk; BG={bg,ru,uk} default bg). Корінь `over.garden/` → geo-редірект у дефолтну папку. UGC НЕ перекладається (запис у мові автора). Кожен `{SSR}`-вузол існує у відповідних мовних варіантах.
2. **Замок локації.** На КОЖНІЙ публічній сторінці/URL — лише ГРУБИЙ регіон; точні координати ніколи в HTML/`title`/URL/sitemap ‹AC-S9b; ENTRY §5›.
3. **Публічно-за-замовчуванням.** Приватних записів немає; єдина вісь видимості = локація ‹AC-S9a›.
4. **Auth-gating (D1).** Гість читає ВСЕ; акаунт — на будь-яку дію-запис (виняток: лайки анонімні). Стіна на «Зберегти». 4 методи входу (пошта/Google/Facebook/Apple).
5. **Видалення→410 + erasure-on-request (D5).** Будь-який публічний URL при видаленні → HTTP 410 Gone + де-індексація. Видалення акаунта НЕ стирає авто; стирання — за запитом, однаково UA+BG (анонімізація-A: PII геть, лінійні ребра-надгробки). Стан кожного `{SSR}`-вузла.
6. **noindex-стани (D2/D6/D7).** Профілі, повний граф-родовід, крос-сторінки-до-порогу, вільні теги — публічно-видимі, але НЕ індексовані.
