## Acceptance criteria

1. Define a consistent prominent search input, compact primary modes and secondary filter entry point with applied count. Search scope is explicit; do not merge owned destination search with the public catalogue.
2. Desktop may expose frequent filters; mobile uses a labeled sheet with current values, result action and separate Clear filters. Close is named Close and preserves committed state, never Reset all.
3. Specify draft-vs-applied behavior and apply/cancel/back contracts consistently. Preserve query/filter/back position and pagination; empty filtered results offer clear reset without erasing unrelated query text.
4. Keep plants/animals selection in one place; meaningful tabs use proper semantics. Avoid scrollbars and clipped chips when labels grow.
5. Public parameterized results follow ADR-0032 /q twins and canonical rules, with usable direct links and no static-page session/searchParams reads.
6. Handle slow search, no results, validation and failure separately, retaining query and showing result count accessibly.
