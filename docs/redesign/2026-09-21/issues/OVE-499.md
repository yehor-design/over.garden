## Acceptance criteria

1. Blog listing/detail use clear reader language, appropriate metadata and shared long-form typography; remove SEO implementation headings from product copy.
2. Markets pages explain their actual current purpose and link relevant content; do not invent commerce, prices, checkout or location tracking.
3. EPPO/source explorers expose reference provenance with searchable bounded records and distinct technical context. They are not competing gardener front doors.
4. Build current existing surfaces only. News/blog database entities, translation generation, mixed-feed merge and editorial pipeline remain owned by <issue id="a25cb16b-64c4-4b22-9b5e-6065c16e5a74" href="https://linear.app/overgarden/issue/OVE-381/news-articles-become-a-first-party-entity-owner-composer-public-page">OVE-381</issue>/382/383/384/401/402/406/409/437/438.
5. Document compatible article/editorial component contracts for those existing tasks, including no-author news and source disclosure. Existing static pages cannot falsely imply an already shipped database/editorial capability.
6. Preserve canonical addresses, public static bytes, source attributions, locale grouping and actual unavailable/error states.
