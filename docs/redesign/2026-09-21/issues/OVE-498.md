## Acceptance criteria

1. Give hub/topic pages descriptive navigation and scoped search using current supported content, with readable answer/guide previews.
2. On answer/guide detail separate advice, sources, qualifications and related first-hand observations. Replace misleading product-principle evidence with actual sources or explicitly state insufficient evidence; do not generate unsupported horticultural claims.
3. Keep product help distinct from gardening knowledge. Source provenance and editorial disclosure are accessible without overwhelming the answer.
4. Use one related-content section with relevant labels; no duplicate recommendation blocks or keyword-stuffed SEO headings.
5. Preserve current locale availability, hreflang, structured data, canonical URLs and public indexability rules.
6. Support long reading, heading navigation, citations, no results and partial unavailable evidence with shared typography and accessible links.
