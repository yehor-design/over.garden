## Acceptance criteria

1. Load existing content into the shared editor with exact destination and date; retain supported document blocks and permanent entry URL when saving.
2. Clean close is immediate. Dirty close/Escape/internal navigation asks Stay or Discard with focus management; browser reload warning uses supported browser behavior and does not promise recoverable drafts.
3. A failed save retains text/media in memory and exposes retry. Session recovery must honestly state limitations across full-page auth navigation; never persist journal text locally as a hidden workaround.
4. Place delete in a contextual destructive menu separated from Save/Publish. Confirmation names the entry and actual consequences; cancel returns focus and leaves content unchanged.
5. Treat edit/delete success only on server acknowledgment and invalidate correct public views. Preserve current tombstone/address rules.
6. Test direct edit links, permission loss, stale/deleted entry, double-submit and return to original timeline position.

## Proof
