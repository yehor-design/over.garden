# Correct public-first, media and deletion promises throughout the product

https://linear.app/overgarden/issue/OVE-476/correct-public-first-media-and-deletion-promises-throughout-the

## Outcome

Users understand that Publish creates a public entry and that unsent writing is transient. Remove factual contradictions before the new composer ships.

Audit traceability: OG-UX-003, OG-UX-004, OG-UX-037. Baseline audit: 2026-09-21, commit e554aec506e84ec6f8304c4704084671ed19f399. Recheck current main before editing; old observations may have changed.

## Acceptance criteria

1. Inventory FAQ, help, first-publication disclosure, privacy, erasure, composer hints and localized strings; map each claim to its actual server/data contract.
2. Remove private-first, saved-draft, original-image retention and server-processing promises where untrue. Explain browser WebP processing and public indexing in plain language without exposing implementation details in the main flow.
3. Distinguish journal transient input from owner editorial pipeline drafts allowed by ADR-0030; do not delete the latter promise or capability.
4. Describe deletion and retention using current runtime behavior; do not invent instant erasure from search engines or external copies.
5. Update UK/BG/RU together, including disclosure version behavior if the actual agreement changes; preserve meaningful acceptance receipts and avoid unnecessary repeated consent.
6. Ensure support and privacy remain reachable before sign-in and after an error.
