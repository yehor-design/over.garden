## Owner decisions this task implements

The owner authorizes complete restructuring of layout, pages and functional groups. Threads leads style, [vc.ru](<http://vc.ru>) supplies centered layout and applicable content interactions, Airbnb informs progressive setup. Phosphor is the only UI icon family; Thiings supports illustrations with unrestricted owner-directed selection and no paid purchase/license-review gate. Fast writing to any of many owned spaces/objects takes precedence over decorative dashboards.

## Acceptance criteria

1. Commit the audit package and this execution plan so a fresh checkout contains the actual findings, screenshots and manifest; verify no personal tokens or private data are added.
2. Create an old-to-new route/function matrix for every family in ROUTES.md: primary user job, audience, primary action, secondary information, destination and responsible issue. Existing public permalinks remain canonical.
3. Define Home/feed, Explore, My garden, Activity and account utilities as distinct jobs. Split timelines from settings and provenance. Record desktop/mobile nav labels and active-route rules; do not expose owner controls to ordinary members.
4. Produce linked low-fidelity wireflows for same-name object selection, a space observation, first object, changing destination mid-composition, community writing and failed publish. Use at least 3 spaces and 100 objects, including unassigned objects.
5. Amend the old Linear/Notion/GitHub visual priority to Threads, centered [vc.ru](<http://vc.ru>) shell plus applicable social patterns, Airbnb progressive setup, Phosphor-only interface icons and Thiings illustration direction. Resolve fixed composer width/gutter without deleting supported blocks.
6. Define measurable action budgets: contextual open 1 activation; global recent destination open+select 2; Publish explicit and separately counted. Search typing and media picking reported separately. Pick one transaction model for new destination+first entry and state what persists if publication fails.
7. Create a transition plan that keeps each intermediate merged page usable. Research with recruited gardeners is desirable but not falsely claimed; executable fixture walkthroughs are required now.
