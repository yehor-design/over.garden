## Acceptance criteria

1. Lay out concise identity, real evidence/experience and supported add/write actions before exhaustive forms. A 621-form example must not dominate the first screen.
2. Move/search/paginate forms and aliases in a secondary register view with stable return context. Preserve every reachable record and canonical form URL.
3. Separate externally sourced botanical facts, editorial mentions and actual first-hand journals. Display sources/factual uncertainty where relevant.
4. Do not expose indexing eligibility as user-facing content and do not relax evidence thresholds merely to fill a redesigned page.
5. Use meaningful reference images with attribution where present; Thiings is not a scientific identification photograph.
6. Handle unknown/common-name-less entities, no experience, retired aliases, plant/animal variants and bounded failure; no fabricated text to make sparse pages look complete.

## Proof

Fixture proof with 0/1/621 forms, organism/form back navigation, referenced evidence and correct indexability; static served HTML plus mobile/keyboard register interaction.
