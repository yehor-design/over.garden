# Recompose the public feed with Threads hierarchy and vc.ru reading affordances

## Outcome

Visitors scan who wrote what, where it belongs and when it happened before a large photo; feeds and journal discovery use a consistent reading grammar.

Audit traceability: OG-UX-010, OG-UX-014, OG-UX-015, OG-UX-016, OG-UX-029, OG-UX-030, OG-UX-041. Baseline audit: 2026-09-21, commit e554aec506e84ec6f8304c4704084671ed19f399. Recheck current main before editing; old observations may have changed.

## Owner decisions this task implements

The owner authorizes complete restructuring of layout, pages and functional groups. Threads leads style, [vc.ru](<http://vc.ru>) supplies centered layout and applicable content interactions, Airbnb informs progressive setup. Phosphor is the only UI icon family; Thiings supports illustrations with unrestricted owner-directed selection and no paid purchase/license-review gate. Fast writing to any of many owned spaces/objects takes precedence over decorative dashboards.

## Acceptance criteria

1. Order ordinary journal cards author/avatar→object/space context→text→optional media→social actions. Respect first-party news no-author contract if that entity exists; do not manufacture a person for editorial items.
2. Adapt [vc.ru](<http://vc.ru>) explicit feed modes, topic/community attribution and readable expansion, without adding ranking/personalization unsupported by current backend. Following/latest modes must reflect actual data semantics.
3. Distinguish publication date from observation date in expanded metadata; use consistent meaning across feed and directories.
4. Remove repeated plants/animals controls. Preserve result/back context, stable paging and canonical entry links; compact cards must not become nested-link click traps.
5. Use natural/bounded image proportions and useful excerpts with accessible Read more. No mandatory giant hero for a short text note; image captions/alt are meaningful and not repeated post titles by default.
6. Scope UGC lang to UGC only; localized chrome dates retain interface language. Preserve static content in served bytes and valid no-JS links.
7. Define shared card variants for existing journal/article types, but leave not-yet-built news merge/cursor backend to <issue id="064838c8-3a1c-4117-999a-c365cb9e8b4a" href="https://linear.app/overgarden/issue/OVE-382/news-articles-appear-in-the-home-feed-as-a-peer-item-merged-on-one">OVE-382</issue>.
