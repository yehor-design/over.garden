## Acceptance criteria

1. Implement the workspace space route agreed in IA; mark new path in the change log and keep existing links functional. Do not invent a new public space permalink without address-law design.
2. Show space identity, a contextual Write action and clear Objects/History views when needed. Label whether an aggregate entry belongs to the space itself or a child object.
3. Keep one entry identity in aggregates: no copying object entries into additional space posts. Stable pagination and dates use the agreed chronological meaning.
4. Space settings/rename/move/delete are a secondary section with explicit consequences determined by existing backend. Never silently delete child objects to make a UI button work.
5. Write opens the space destination directly; optionally change to a child via the common picker. Creating an object here preselects the parent space.
6. Support empty space, many children, unassigned objects elsewhere, renamed space and bounded loading/error states.
