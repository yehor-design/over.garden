# Threads foundations and the single icon family

Implementation date: 2026-09-21. Baseline: `a84b1c17cdae430936197bfae164fb7abdcfa22f`.
The exact tested commit, CI run, merge and production deployment belong to the
PR/Linear release receipt. This document records implementation and local proof;
it does not independently certify production or the complete redesign.

## Result and boundaries

Shared controls now use dark neutral actions, restrained surfaces, explicit
pressed states, consistent rounded geometry and 44px default action targets.
Google Sans and Geist Mono remain the fonts. Existing spacing, type, elevation
and reduced-motion scales remain authoritative. Green carries meaningful status,
not the default action. Content photographs retain their context-specific sizing
policy in DESIGN.md; a universal cover crop is not introduced.

The same primitives serve guests, gardeners and the sealed owner. This is the
foundation, not the later navigation or page-family redesign. Public-only journal
publishing, transient unsaved input, server mutation authorization and static
public document contracts remain unchanged. No schema migration is required.

## Reference decisions

The previously ratified Threads references remain the style authority. The actual
Mobbin screens inspected again for this implementation were the
[focused composer](https://mobbin.com/screens/fc7ed966-1324-4b58-a75d-55671c3db8c9)
and its [photo state](https://mobbin.com/screens/fc51e487-b864-41ec-a3de-319f50030ead).
The transferred patterns are quiet neutral chrome, a clear writing area, restrained
dividers and a recognizable action hierarchy. They are not a claim that this
foundation alone implements the destination picker or the new three-column shell.

## Icon migration

`ove-477/icon-inventory.json` maps 198 former runtime imports across 72 files to
83 Phosphor glyphs. Three Lucide type imports and the CSS loading ring were also
replaced. Lucide is removed from the package manifest and lockfile; scaffold
configuration selects Phosphor. The source gate rejects competing families,
bespoke functional SVG, emoji control glyphs, direct vendor imports outside the
adapter and broad local runtime imports. Brand marks and favicons remain explicit
exceptions; authored callout emoji remains document content.

The installed `@phosphor-icons/react@2.1.10` README and package exports were checked
against the [official repository](https://github.com/phosphor-icons/react).
Each `components/icons/<Glyph>` module imports one official SSR module and applies
the shared typed adapter. No client provider is necessary. Sizes are 16/20/24px;
regular is the default, fill indicates a selected navigation/social action.
The adapter hides decorative glyphs from assistive technology; the enclosing
control retains its text or accessible name. Persisted journal documents do not
change. Type-only imports may use the local index; runtime consumers may not.

## Interaction and accessibility evidence

The local interactive specimen is generated by `pnpm components:render` after a
production build. It imports the actual components, CSS, font classes and font
files. It creates ignored local artifacts, not a new product route. Its six
registered browser cases cover UK/BG/RU at 320 and 1440px:

- Five button variants in default, disabled and pending states; visible focus
  and hover; field error association and disabled input; selected tabs; select,
  menu, dialog, sheet, toast, skeleton and empty state.
- Actual 16/20/24px glyph bounds and default action height of at least 44px.
- Arrow-key tabs/menu, dialog focus containment and Escape focus return for
  dialog, sheet and menu.
- Reduced-motion animation suppression, forced-colors visible focus, and 200%
  root text sizing without horizontal overflow. The existing mobile shell suite
  also exercises text-spacing overrides, 44px targets and 400% reflow.

`globals.test.ts` measures color pairs from the actual OKLCH tokens, including
pressed action. White/action is 17.89:1, white/hover 9.34:1 and white/pressed
19.75:1. Normal text clears 4.5:1 and meaningful control boundaries clear 3:1.
Disabled controls and decorative separators are not falsely presented as normal
text or meaningful boundaries. Automated checks supplement visual inspection.

The screenshots in `ove-477/` show actual component states, dialogs, menus,
forced colors and text zoom. Desktop and mobile product navigation were manually
inspected in the in-app browser; search and mobile navigation returned focus to
their trigger on Escape. The editor selection controls were visually inspected
from the existing publish/reorder browser scenario. The full browser gate covers
the owner controls and their accessibility, static documents/no-JS forms,
authenticated publication, validation, social actions and hard-load degraded
workspace session handling. These local scenarios use an isolated test database.

## Bundle measurement

The before/after JSON files list every initial script resource referenced by the
same prerendered `uk/support.html`, compressed with the same gzip settings:

| Build | Chunks | Raw bytes | Gzip bytes |
| --- | ---: | ---: | ---: |
| Baseline main | 23 | 1,213,132 | 366,332 |
| Named local glyph modules | 24 | 1,276,841 | 383,634 |

The net cost is 17,302 gzip bytes (+4.72%). An initial wrapper barrel added about
47KB gzip; named consumer imports removed that avoidable overhead. The remaining
cost includes Phosphor's supported glyph variations. No whole-library runtime
lookup or barrel is imported into guest chrome. This is a controlled resource
comparison, not a network timing, deferred-chunk total or completion claim for
the separate performance tasks.
